Trata-se de um projeto básico para estudo do javascript.

A aplicação permite ao usuário adicionar quantos números este desejar, desde que estes números estejam entre 1 e 100, sem repetição.

Após o cadastro da quantidade desejada de números, a aplicação retornará a quantidade total de números cadastrados, o maior valor, o menor valor, a soma de todos e a média.
